# Fixtures

Keep small, synthetic, redistributable image and macro fixtures here. Record each fixture's purpose, provenance and expected result. No real research images have been added.

Keep private datasets in the ignored root `data/` folder and generated results in `outputs/`.

two-squares.png is a deterministic 64 × 64 grayscale image generated by fixtures/create_fixture.py: 256 pixels at intensity 100, 256 at 200, and 3,584 at zero. Mean intensity is 18.75; inversion gives 236.25. Area is 4,096 square pixels. No spatial calibration is attached.

invert-command.wav is generated locally with Windows System.Speech.Synthesis.SpeechSynthesizer from “Invert the image.” It is a 1.94-second synthetic voice fixture, not user speech. It verifies the software path but does not establish accuracy on human speech, accents or noise.
