# Pitch material

[Luma-Pitch-v3.pptx](Luma-Pitch-v3.pptx) is a seven-slide editable deck with actual QuPath viewer evidence and source/provenance notes. The final slide states the current live-voice funding blocker.

The measured software fixture is recorded in [integration-evidence.json](integration-evidence.json). Its counts describe a chosen detection and threshold on a public sample, not validated biological ground truth.

The authoring source uses the Codex bundled `@oai/artifact-tool` presentation runtime and stays in the local build workspace. All required slide text remains editable in PowerPoint. See [the demo guide](../DEMO.md) for the spoken storyline and preparation.
