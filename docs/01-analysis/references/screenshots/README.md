# Screenshots: pinned Fiji runtime

All images are captures of the real pinned runtime. The runtime is **Fiji 2.18.1-SNAPSHOT / ImageJ 1.54p (`(Fiji Is Just) ImageJ 2.18.0/1.54p`) / Java 21.0.7 (bundled Zulu) / Windows 11 Home 10.0.26200**, at 150 % display scaling, pin `f66953972bb5ed85b8ab0273e4294af5b03136c28c9ef617e24556bca523bafa`.

- **Capture date and session.** All captures were taken on 2026-10-17 by agent G4 for [A04](../../01-product-users/A04-fiji-ui-audit.md).
- **Content.** Only synthetic images were used (`synthetic-blobs`, `synthetic-blobs-threshold`, `hyperstack-demo`), all generated by `probes/P50-gui-staging.groovy`. No user data was used.
- **Launch command.** Fiji was started from `C:\Users\arnav\Documents\dev\Fiji`:

  ```
  fiji-windows-x64.exe -Dimagej.updater.disableAutocheck=true --java-home=<Fiji>\java\win64\zulu21.42.19-ca-jdk21.0.7-win_x64 --allow-multiple --run <abs path>\P50-gui-staging.groovy
  ```

  The final run was PID 32508. Fiji was then killed by PID, and nothing was saved.

**Methods.** The Windows input desktop was the screen saver for the whole session, so screen-copy capture was impossible (see `probes/P52-session-side-effects.txt`). Neither method below reads screen pixels, so no other window or the desktop can appear.

- **A, `PrintWindow`.** `probes/P51-capture-fiji-windows.ps1 -Mode printwindow -TrimX 8 -TrimW <javaW-8> -TrimH <javaH-8>`. This uses Win32 `PrintWindow(PW_RENDERFULLCONTENT)` on a window owned by the Fiji PID. Java renders this at 100 % scale, so the image is cropped to the Java logical window size. The capture includes the native title bar and the AWT menu bars. Known artefact: the main-window toolbar canvas renders blank.
- **B, in-process.** `Window.printAll()` is called from `P50-gui-staging.groovy` (`snapWin`) inside the Fiji JVM. It renders the Java component tree only, so native title bars and AWT menu bars are not drawn. For `ImageWindow`s the subtitle line is kept.
